# Redumper Report

Generates a human-readable report with detailed information from [Redumper](https://github.com/superg/redumper) log files (`.log`, `.state`, `.skeleton`, `.toc`, `.manufacturer`, `.physical`, etc.).

```
redumper_report.exe disc.log
```

Ensure that all log files are all in one directory (not in a zip), and have not been renamed (i.e. `disc.log` has an associated `disc.state`, etc.).
